# ADR 0005: Kontrak C ABI

Status: diterima (v0.1.0)

## Keputusan

C ABI (`include/vhdp/vhdp.h`) adalah kontrak kompatibilitas jangka panjang:

- **Struct berversi**: awali dengan `{uint32_t struct_size; uint32_t abi_version;}`;
  pemanggil mengisi keduanya; library menolak mismatch (`VHDP_E_ABI_MISMATCH`) dan
  reserved fields non-nol.
- **Opaque handles** (`vhdp_context`/`vhdp_config`/`vhdp_session`), dimiliki
  pemanggil antara `*_create`/`*_destroy`.
- **Integer fixed-width bernama** untuk semua status/flag/kind (`typedef uint32_t
  vhdp_status_t` dst.), **bukan** `enum` C, agar ukuran/ABI stabil lintas toolchain.
  Tidak mengekspos `std::string`, `bool`, bitfield, reference/template C++, atau
  pointer ownership ambigu.
- **Semua fungsi `extern "C"`**; exception tidak melewati boundary (lihat ADR 0003).
- **Export allowlist** via linker version script (`src/capi/libvhdp.map`) +
  `-fvisibility=hidden`; hanya `vhdp_*` yang diekspor. Snapshot simbol
  (`tests/abi/exported_symbols.txt`, `T-ABI-SYMBOLS`) memverifikasi tidak ada
  kebocoran simbol STL/C++ dan daftar cocok persis.
- **Ownership/callback lifetime** dan **thread-safety** didokumentasikan di header.
  Re-entrant `wait`/`destroy` dari callback session yang sama menghasilkan
  `VHDP_E_BUSY`.
- **Wrapper C++ tipis** (`vhdp.hpp`) di atas C ABI; ABI compiler/libc++ internal
  bukan kontrak stabil. Header C dan C++ self-contained (diuji `T-ABI-HEADERS-*`).

## Versi

`VHDP_ABI_VERSION = 1`. Perubahan yang kompatibel menambah fungsi/field di ruang
reserved dengan menaikkan `struct_size`. Perubahan tak kompatibel menaikkan
`abi_version` dan (bila perlu) node version script baru.
